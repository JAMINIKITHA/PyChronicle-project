# PyChronicle

## AST-Powered Time-Travel Debugger

PyChronicle is a Python debugging tool that analyzes code structure, records execution flow, and provides a timeline view of program execution.

## Features

- AST based code analysis
- Function, class and import detection
- Code metrics generation
- Execution tracing using Python sys.settrace
- SQLite storage for execution history
- Textual based TUI viewer
- Flask web interface
- Trace report export (CSV)
